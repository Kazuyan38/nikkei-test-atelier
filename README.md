# Nikkei Atelier — 日経TEST 対策帳

日経TEST の6分野（経営環境／企業戦略／会計・財務／法務・人事／マーケティング・販売／生産・テクノロジー）を、
**基本単語テスト・知識確認（2026年の具体例つき）・演習**で往復する個人用の学習アプリ。用語とニュースは保管庫からキーワード検索できる。

公開URL: https://kazuyan38.github.io/nikkei-test-atelier/

## 使い方
- スマホ・PC のブラウザで上の URL を開く。ホーム画面に追加すればアプリのように使える。
- ローカルでは `index.html` をダブルクリックで開ける（サーバ不要・オフライン動作・外部 CDN 不使用）。
- 学習記録（習熟度・保存・演習履歴）は端末のブラウザ（localStorage）に保存される。端末間の同期はしない。
- 一度オンラインで開けば、以後は圏外でもホーム画面から起動できる（`sw.js`）。HTML と `data.js` はネットワーク優先なので、オンライン時は常に最新版、圏外時はキャッシュを表示する。
- ファイル構成を変えたとき（ファイルの追加・改名）は `sw.js` の `VERSION` と `SHELL` を更新する。内容の更新だけなら不要。

| 画面 | 内容 |
|---|---|
| 単語テスト | 3D でめくるカード。「知ってる／あやふや／知らない」の自己採点（Leitner 方式 0〜4、3 以上で習得語）。苦手のみ・未学習のみで出題 |
| 知識確認 | 分野別に定義＋2026年の具体例＋関連ニュース。「理解した」で習得語に加算 |
| 演習 | 応用問題（計算・因果・時事）38問＋用語から自動生成する問題（定義→用語／用語→定義／事例→用語）。解説・分野別正答率・間違い直し |
| 保管庫 | 用語・ニュースの横断検索（AND、かな/カナ・全角/半角を同一視）、分野・種別・★保存で絞り込み |

キーボード: 単語テストは Space でめくる・1/2/3 で採点、演習は 1〜4 か A〜D で回答・Enter で次へ。

## 内容を足す
`data.js` の配列に同じ形のオブジェクトを追加するだけで、検索・出題・分野別集計に自動で反映される。
- `terms`: 用語（`rel` に関連ニュースの id）
- `news`: 2026年のニュース（`src` に出典 URL。数値は出典の公表時点の値）
- `drills`: 応用問題（`a` は正解の添字）

## 構成
- `index.html` — UI・ロジック・WebGL の 3D 地球儀（WebGL 非対応時は Canvas2D に自動切替）。筆記体フォント Pinyon Script（Latin サブセット）を base64 で内蔵
- `data.js` — 用語122・ニュース22・応用問題38（データ時点 2026-10-07）
- `og-image.png` / `robots.txt` / `sitemap.xml` — 公開用
